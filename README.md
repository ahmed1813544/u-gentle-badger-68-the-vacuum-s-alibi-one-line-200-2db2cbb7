A stdlib-only Python program (`main.py`) that writes the funniest one-line
excuse a robot vacuum can give for missing a spot to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deadpan, a little smug about its
sensors, with a surprise detail and the punch at the end — in 135 characters.
